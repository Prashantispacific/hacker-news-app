1. Design, Typography & Ergonomics
OLED True Black Support
Halation-safe comfort on dark viewports
 ❌ No
Default #f6f6ef beige only; no dark mode without browser extensions.
 ✨ Native OLED
Default halation-safe #0A0A0A with one-tap toggle to #000000 True Black.
 ⚠️ Dark Gray
Most use standard blue-gray #1e293b or card containers with shadows.
Cardless / Anti-Slop Layout
Whitespace as primary content separator
 ⚠️ HTML Tables
Dense 2007 HTML table layout with minimal row breathing room.
 ✨ Zero UI Slop
Zero cards, zero borders, zero drop shadows. 20px–24px vertical whitespace as natural separator.
 ❌ Boxy Cards
Heavy Material/Tailwind cards, round pill wrappers, and nested borders.
Tri-Font Typography
Sans, Monospace, and Editorial Serif
 ❌ Monolithic
Single system Verdana / Arial for all titles, metadata, and comments.
 ✨ Curated Hierarchy
Clean sans (Inter) for titles, crisp JetBrains Mono for metadata, and Newsreader for articles.
 ⚠️ Single Font
Usually system sans-serif only (-apple-system or Roboto).
Split-Pane Desktop Layout
Dual-column responsive workspace (≥1024px)
 ❌ Single Column
Full page reload for every item; comments always open in new page.
 ✨ Split-Pane & Auto-Collapse
Left feed list + right discussion pane; automatically collapses feed to give 100% width when reading articles.
 ⚠️ Limited
Some (like OctoHN) offer fixed 50/50 splits without reader collapse.
Mobile Touch Ergonomics
Bottom nav bar, swipe gestures, safe areas
 ❌ Desktop Only
Viewport zoom required; tiny tap targets and header navigation at the top.
 ✨ Mobile Native Feel
Floating bottom pill bar (Feed · Reader · Thread), horizontal touch swipe navigation, safe-area padding.
 ✅ Supported
Most mobile web apps provide a bottom bar, though gesture support varies.
Desktop Hotkeys
Full keyboard-driven navigation
 ❌ None
Tab navigation only; no single-key shortcuts.
 ✨ 7 Hotkeys
j/k (next/prev), o (original link), c (thread), r (reader), / (search), f (fold root).
 ⚠️ Partial
Refined Hacker News extension supports j/k only.
2. Discussion & Signal Suite (Comments)
1px Guide Rails with Hover Highlighting
Subtle visual tracking of comment nesting
 ❌ Invisible
Whitespace indentation only; impossible to trace deep reply chains.
 ✨ 1px Guide Rails
Subtle border-white/[0.08] guide rails with active hover illumination and click-to-fold.
 ⚠️ Thick Borders
Often 2-3px thick solid borders or colored rainbow borders that add noise.
Inline Branch Folding with Reply Count
Collapsing threads with exact descendant totals
 ⚠️ Basic [-] Collapse
Collapses to a single line without showing how many child replies were hidden.
 ✨ [+] N Replies Badge
Shows exact descendant count ([+] 14 replies collapsed); tap rail or author to toggle.
 ✅ Common
Several modern clients support count collapse.
Clamped Indentation
Prevents right-side horizontal text squeeze on mobile
 ❌ Unclamped
Deep comments indent indefinitely, squeezing text into 1-character columns.
 ✨ Max 3-4 Levels
Clamped at 3 levels on mobile with breadcrumb ↩ replying to @author for full readability.
 ❌ Squeezed
Almost all web clients squeeze horizontal width or force horizontal scrolling.
OP Stepper
Jump between Original Poster comments
 ❌ Missing
No mechanism to follow the author's responses in Ask HN or Show HN.
 ✨ Floating ▲ 1 of X ▼
Floating controller tracking all OP comments with smooth jump and pulse highlight.
 ❌ Missing
Not found in Hax, HackerWeb, or Materialistic.
Thread Link Drawer
Extract and filter every external URL in comments
 ❌ Missing
Must manually read every comment to find external links and papers.
 ✨ Link Drawer with Filter
Extracts and deduplicates all external links (including archive.org) with search filter and domain chips.
 ❌ Missing
Unique to Hacker News by PG signal suite.
Fold-to-Root
One-tap view of all top-level commentary
 ❌ Missing
Must manually scroll past hundreds of sub-replies.
 ✨ One-Tap / 'f' Key
Folds all nested threads simultaneously to scan high-level root arguments in seconds.
 ❌ Rare
Requires manual script injection or custom tampermonkey userscripts.

Reading Comfort Controls
Typography, width, line-height, and warm tint adjustments
 ❌ None

 ✨ Reader Settings Panel
Adjust font size (14px–26px), line-height, reading width, and warm amber/sepia palette.
 ❌ None
Fixed stylesheet styles without runtime reader comfort knobs.
4. Channel Filtering & Content Curation
Deterministic Channel Knobs
Topic channels with deterministic filter rules
 ⚠️ Static Pages
Static endpoints only: /news, /newest, /ask, /show, /jobs.
 ✨ Curated Channels
#all, #systems, #showcase, #essays, #links, #ask, #jobs, #saved.
 ⚠️ Basic Tabs
Mirrors standard Top/New/Best/Ask/Show without topic classification.
Custom Channel Filter Builder
Build user-defined channels with regex/keywords/domains
 ❌ Missing
No custom curation or channel creation allowed.
 ✨ Custom Channel Studio
Create channels matching domains (github.com, arxiv.org), keywords, or score thresholds.
 ❌ Missing
Users are locked to predefined feeds.
Client-Side Mute List
Negative filtering for keywords, domains, and authors
 ❌ Server-side Flags Only
Requires 501+ karma to downvote; no personal keyword or domain mute.
 ✨ Local Negative Filter
Mute keywords (e.g. "crypto", "AI hype"), domains, and authors locally with hidden count badge.
 ⚠️ Extension Dependent
Requires Refined HN Chrome extension; not available in standalone web apps.
Instant Algolia Search Modal
Full-text search overlay with instant typeahead
 ⚠️ External Redirect
Redirects to separate domain hn.algolia.com with completely different UI.
 ✨ Instant Modal ('/')
In-app modal with debounce, live Algolia search, direct story open, and discussion preview.
 ⚠️ Varying
Some clients embed Algolia, others have no search functionality.
5. Architecture, PWA & Performance
Zero Backend Server Architecture
100% static client deployable to Netlify/Vercel/CDN
 ❌ Centralized Server
Monolithic Arc server running on FreeBSD; susceptible to DDoS and downtime.
 ✨ Zero Server / 100% Static
No custom server, Node proxy, or backend database. Static files on edge CDN.
 ⚠️ Node/Next.js Proxies
Most require an active backend server (Node.js, Express, or Next.js SSR) to proxy requests.
Offline PWA & Service Worker
Installable progressive web app with offline caching
 ❌ No PWA
No service worker, no web manifest, completely breaks when offline.
 ✨ Full PWA + Workbox
Precached app shell, Workbox runtime caching for Firebase/Algolia, install prompts.
 ⚠️ Basic Manifest
Some offer a basic manifest, but lack comprehensive offline API caching.
Local State Persistence
IndexedDB store for bookmarks, read history, and channels
 ⚠️ Server Account
Requires logging in with password; browser history tracks visited links.
 ✨ Local IndexedDB (`idb-keyval`)
Zero account required; bookmarks, custom channels, and read states persist locally on-device.
 ⚠️ LocalStorage
Usually synchronous localStorage limited to 5MB, which can choke on large trees.
Privacy & Data Tracking
Zero telemetry, cookies, or user profiling
 ✅ Minimal
Session cookies for login; no third-party trackers.
 ✨ Privacy-First
No authentication cookies, zero user profiling, optional aggregate privacy-first Cloudflare beacon.
 ⚠️ Varying
Many include Google Analytics, Sentry, or third-party ad tags.
